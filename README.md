# Reward Analysis Site

This repo contains a single-page HTML report for SKIO / Recharge / Loop reward analysis.

## Local files

- `index.html` is the GitHub Pages entry file.
- `reward-analysis.html` is the editable source version.
- `reward-analysis-shareable.html` is the single-file shareable version.
- `assets/` contains embedded screenshots used by the report.

## Publish to GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings > Pages**.
3. Set **Source** to **GitHub Actions**.
4. Push to `main`.

The workflow in `.github/workflows/pages.yml` will deploy the site automatically.
